This is a copy of the AHK Macro Recorder script with some modifications. AHK Macro Recorder is an AutoHotkey script that enables you to record keyboard and mouse macros, based on the work of feiyue. See the original [here](https://www.autohotkey.com/boards/viewtopic.php?f=6&t=34184&sid=03fb579fcaef3c186e5568b72390ef9e)

See [Releases](https://github.com/raeleus/AHK-Macro-Recorder/releases) for the latest download of AHK Macro Recorder

See [tutorial video](https://youtu.be/9_l0rIXO9cU) on the AHK Macro Recorder script.

The documentation is the video, so make sure to watch it.

[Install AutoHotkey v2](https://www.autohotkey.com/).

The differences between the original AHK Macro Recorder and the modifications made in in this file are:
1- Added additional parameter for file folder of recorded macro
2- Change viewsource action for exitapp
3- Make the tooltip more visible
